# AISecLab 后端 —— 部署说明

> 本包是**源码部署包**（Linux 服务器 / Docker / 裸机 venv 都能用），不是 Windows 免安装 exe。
> 微信、手机 App、模型都不要装在这台机器上 —— 这里只跑一个 FastAPI 服务。

---

## 0. 五分钟最小路径（有 Docker 就照这个走）

```bash
unzip aiseclab-backend-*.zip
cd aiseclab-backend

cp .env.example .env      # 不填也能起，起完再填也行（见 §3）
docker compose up -d --build

curl http://127.0.0.1:8000/health     # 期望 {"status":"ok"}
```

看到 `{"status":"ok"}` 就成功了。手机 App 里填 `http://<这台机器的局域网IP>:8000`。

停止：`docker compose down`（数据卷保留）或 `./stop.sh`。

## 1. 包里有什么

| 文件 | 用途 |
|---|---|
| `app/` | 全部后端源码（14 个模块） |
| `requirements.txt` | 运行依赖，只有 4 个直接依赖 |
| `Dockerfile` | 镜像定义（python:3.11-slim，非 root 运行，带 HEALTHCHECK） |
| `docker-compose.yml` | 一键编排（端口、环境变量、data 卷、内存上限） |
| `.env.example` | 配置模板，**复制成 `.env` 再填** |
| `start.sh` | 一键启动，自动选路：有 Docker 走容器，没有走本机 venv |
| `stop.sh` | 一键停止 |
| `deploy.py` / `deploy.bat` | 无 Docker 时的跨平台启动器（自动建 venv、装依赖、起 uvicorn） |
| `smoke_test.py` | 离线冒烟：编译全部模块 + 打桩跑完整判定链（含负对照），**不联网、不花钱** |
| `README.md` | 完整文档（Rocky 9.2 专项、systemd、反向代理、接口清单） |
| `data/` | 空目录，compose 会挂载到这里 |
| `部署说明.md` | 本文件 |

## 2. 三条部署路径，怎么选

| 场景 | 走哪条 | 命令 |
|---|---|---|
| 有 Docker（推荐，评审 / 云主机） | 容器 | `./start.sh --docker` 或 `docker compose up -d --build` |
| 没 Docker，有 Python 3.9+ | 本机 venv | `./start.sh --local`（前台运行，Ctrl+C 停） |
| Windows，装了 Python | 双击 | `deploy.bat` |
| 不想管进程、要开机自启 | systemd | 见 `README.md` §4 |

`./start.sh` 不带参数时会自动判断：装了 Docker 就走容器，没装就走本机 venv。

## 3. 配置（`.env` 里最要紧的四个键）

```bash
JUDGE_BASE_URL=https://api.deepseek.com/v1   # 裁判模型端点，注意不要写 https 成 http
JUDGE_API_KEY=sk-xxxx                        # 裁判模型密钥
JUDGE_MODEL=deepseek-chat                    # 裁判模型名
API_TOKEN=                                   # 公网/共享机器务必设一个随机串
```

- **全都不填也能起服务**，`/health` 照样正常。此时裁判由手机 App 在创建任务时带过来（BYOK）。
  两边都没有才会返回 503，报错信息里写明缺哪个。
- **`API_TOKEN` 建议设**：除 `/health` `/docs` 外所有接口都要 `Authorization: Bearer <token>`。
  不设等于把裁判模型额度公开给任何能访问这台机器的人。
- 其余可选项（并发数、超时、采样次数、护栏模型）在 `.env.example` 里每项都有注释，
  默认值可以直接用，不用动。

### 端口

默认 `8000`。改 `.env` 里的 `PORT`，或临时 `PORT=8080 ./start.sh`。

> 别用 80 / 443 —— 留给宿主机自己的 nginx。要 HTTPS 就上反向代理，见 `README.md` §5。

## 4. 起完怎么验证

按顺序四条，全过就说明这套部署没问题：

```bash
# ① 进程活着
curl http://127.0.0.1:8000/health
# {"status":"ok"}

# ② 接口文档能打开（浏览器访问，不需要鉴权）
curl -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8000/docs
# 200

# ③ 离线冒烟：编译全部模块 + 打桩跑完整判定链（含负对照），不联网
python3 smoke_test.py
# [compile] modules=14 errors=[]
# ...
# [smoke] ALL OK

# ④ 容器健康状态（走 Docker 时才看）
docker compose ps
# STATUS 应为 Up (healthy)
```

③ 只在「装了依赖的那个 Python」里跑才有意义（容器内或 venv 内）。它测的是
**代码是否完整、判定链是否跑得通**，不测上游模型 —— 上游要另外用 App 真跑一轮才知道。

## 5. 手机 App 怎么连

App「设置 → 测试后端」填地址，**只填到端口，不要带 `/v1`**：

```
http://192.168.1.50:8000
```

IP 用这台机器在**同一局域网**的地址（`start.sh` 起完会把各网卡地址打出来，标 `[私网]` 的那条才是）。
设了 `API_TOKEN` 的话，同一页把 token 也填上。

App 内部会自己拼 `/v1/sessions`、`/v1/reports/{id}` 这些路径。

## 6. 排错：七个最常撞的

**Q：本机 `curl` 通，别的机器访问不了。**
防火墙没放行。Rocky / RHEL：`sudo firewall-cmd --permanent --add-port=8000/tcp && sudo firewall-cmd --reload`。
Ubuntu / 云主机安全组同理。

**Q：容器起来了但报 `EACCES` / `Permission denied` 写 `data/`。**
Rocky / RHEL 的 SELinux 默认 Enforcing，绑定挂载要带标签。`docker-compose.yml` 里的
`./data:/app/data:z` 那个 **`:z` 就是标签，别删**。

**Q：`./start.sh` 报 `/usr/bin/env: 'bash\r': No such file or directory`。**
`start.sh` 被转成 CRLF 了。`sed -i 's/\r$//' start.sh stop.sh` 修一下。
（本包里这两个文件是 LF，正常解压不会出这问题。）

**Q：报 `import` 失败 / 模块找不到。**
用错解释器了。base 系统 python 没装依赖，必须用 venv 里那个。
`./start.sh --local` 会自动建 venv，别自己 `python3 app/main.py`。

**Q：`docker compose up` 报 `permission denied` 连不上 Docker。**
当前用户不在 docker 组：`sudo usermod -aG docker $USER`，**重新登录**后再试。

**Q：首次启动日志里有 `[checkpoint] 列目录失败 ... 'checkpoints'`，要不要管？**
不用管，**这是正常的**。检查点目录是"第一次落盘时"才创建的（避免在任何 import 场景留下垃圾目录），
所以全新的部署第一次列目录会找不到。跑第一条任务时它会自己建出来，之后就没了。
想消掉这行也行：`mkdir -p checkpoints`。

**Q：任务跑到一半全部失败，日志里是 `Redirect response '302 Found'`。**
`JUDGE_BASE_URL` 里 `https` 写成了 `http`。部分厂家（如 deepseek）会把 http 302 到 https，
后端有防护会按原 POST 重发一次，但**写对协议头最省事**。

## 7. 安全与数据

- **密钥只放在服务器环境变量里**（`.env` 或 systemd `EnvironmentFile`），不进镜像、不进仓库。
  本包的 `.env.example` 里全是占位值。
- **被测模型的密钥不在服务器留存**：手机 App 在创建任务时传过来，后端只在任务生命周期内
  放在内存 dict 里，重启即失，不落盘。
- **报告目前是内存态**：`sessions` 字典，服务重启就没了。`data/` 卷是预留给报告落盘用的，
  当前挂不挂不影响行为。
- 公网暴露必须走 HTTPS，否则密钥和模型回答都是明文。
